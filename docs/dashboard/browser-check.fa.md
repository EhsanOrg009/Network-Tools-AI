# بازتولید آزمون مرورگر

این آزمون سرور FastAPI، worker امنیت و مرورگر واقعی را به هم متصل می‌کند. دادهٔ شبکه و پاسخ مدل ساختگی‌اند. هیچ دیتابیس عملیاتی، فایل `.env` یا endpoint واقعی استفاده نمی‌شود؛ نشانی‌ها از محدوده‌های مستندسازی‌اند.

## اجرای مستقل

از ریشهٔ مخزن، در سه ترمینال جدا اجرا کنید:

```bash
uv run python scripts/serve_dashboard_fixture.py
```

```bash
google-chrome --headless=new --disable-dev-shm-usage --disable-gpu --remote-debugging-address=127.0.0.1 --remote-debugging-port=9229 --user-data-dir=/tmp/netagent-browser-profile about:blank
```

```bash
node scripts/verify_dashboard_browser.cjs
```

پیش از آزمون باید `npm run build` در پوشهٔ `dashboard` اجرا شده باشد. اسکریپت CDP به Node نسخهٔ ۲۲ یا جدیدتر نیاز دارد و کتابخانهٔ مرورگر جدیدی نصب نمی‌کند. در اجرای ثبت‌شده Node ۲۴ و Chrome نسخهٔ ۱۵۷ استفاده شدند. Chrome در محیط آزمایشی محدود با گزینهٔ `--no-sandbox` اجرا شد؛ این گزینه نیاز محیط آزمون بود.

برای تکرار آزمون، ابتدا سرور fixture را متوقف و دوباره اجرا کنید تا دیتابیس مستقل تازه ساخته شود. پورت‌های ۸۷۶۵ و ۹۲۲۹ باید آزاد باشند. سرور توکن تصادفی و کلید امضای آزمایشی را در پوشهٔ خصوصی زیر `/tmp` می‌سازد؛ ابزار فقط مسیر فایل حالت `/tmp/netagent-dashboard-qa-state` را می‌خواند و پس از پاسخ احرازهویت‌شدهٔ موفق آغاز می‌کند. توکن چاپ نمی‌شود و در تصاویر ورود نیز وارد نشده است.

ابزار تب‌های قبلی متعلق به همین fixture را می‌بندد و تنظیم پوسته/ورود را پیش از بارگیری برنامه در همان مبدأ آزمایشی پاک می‌کند. استفاده از این اسکریپت برای سرور عملیاتی پشتیبانی نمی‌شود. `--inspect` فقط متن غیرحساس صفحهٔ آزمایشی را برای تشخیص توقف ابزار می‌خواند.

## سناریوهای ثبت‌شده

- ورود از فرم واقعی، RTL، خاموش‌بودن حالت خودکار و صفر بودن job پس از بازکردن Security.
- تحلیل فقط یک رویداد در حالت خاموش، نمایش نتیجهٔ همان شناسه و نساختن POST تازه در کلیک بعدی.
- پنجرهٔ تحلیل بومی، غیرقابل‌فوکوس‌بودن ناوبری پس‌زمینه و بستن با Escape؛ فوکوس می‌تواند طبق رفتار بومی مرورگر به نوار مرورگر برسد.
- روشن‌کردن از رابط، ورود رویداد تازه و تکمیل همان کار؛ خاموش‌کردن و نبود job برای رویداد بعدی.
- ده مقصد اصلی و دو جزئیات عامل، از جمله نام میزبان بلند، روی دسکتاپ و موبایل.
- همهٔ مقصدها در پوستهٔ روشن و همهٔ تب‌های عامل، از جمله ورودی ترمینال LTR.
- منوی کامل موبایل، نبود افزایش عرض کل سند و عرض‌های ۳۹۰، ۷۶۸، ۱۰۲۴، ۱۴۴۰ و ۱۹۲۰ پیکسل.
- دسترسی به `/api/docs`، رد API بدون توکن، نمایش فعالیت‌های worker با مدل آزمایشی و خروج از داشبورد.
- بازکردن تاریخچه بدون POST، تحلیل مجدد صریح تنها یک هشدار، حفظ job قبلی، نمایش تاریخچه روی موبایل و چهار فعالیت واقعی worker با مدل ساختگی.
- بازکردن تمام مقصدها در عرض ۳۲۰ پیکسل بدون افزایش عرض کل سند.

جدول‌های عریض در ظرف خود پیمایش افقی دارند؛ نبود overflow کل سند به معنی نمایش هم‌زمان همهٔ ستون‌ها روی موبایل نیست. تصاویر جدول همین رفتار را نشان می‌دهند.

نتیجهٔ اجرای کامل در [رکورد مرورگر](browser-verification.json) و تصاویر در [پوشهٔ تصاویر](screenshots/) ثبت شده‌اند. شکست‌های حین تکمیل ابزار ــ انتظار متن شمارنده، کد کلید ناقص، هم‌زمانی توکن موقت و اسلش انتهای مسیر ــ اصلاح شدند. نتیجهٔ ثبت‌شده متعلق به اجرای تمیز پس از این اصلاحات است؛ خطای منبع مرورگر حذف یا فیلتر نشده است.

اجرای تازهٔ ۲۰۲۶-۱۱-۱۳، ۳۸ سناریو و صفر خطای اجرا/منابع ثبت کرد. پیش از تصویر تاریخچه، ابزار منتظر تکمیل تحلیل در خود رابط می‌ماند؛ موفقیت API به‌تنهایی جای مشاهدهٔ نتیجه در رابط را نمی‌گیرد. این آزمون کیفیت تحلیل مدل واقعی یا اجرای کنسول روی دستگاه ویندوزی واقعی را اثبات نمی‌کند.
