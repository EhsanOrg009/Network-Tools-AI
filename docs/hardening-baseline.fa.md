## محیط و آزمون اولیه

- `uv 0.11.23`؛ `uv python list` اجرا شد. نسخهٔ Python پروژه تغییر نکرد.
- `uv sync --check`: فایل `uv.lock` به‌روز، ۳۶ بسته بررسی‌شده، بدون تغییر لازم.
- `uv run pytest -q`: **۳۳۶ موفق، ۴ skipped** در ۸۴٫۲۰ ثانیه؛ شکست صفر.
- سه آزمون واقعی Ollama نیازمند opt-in بودند؛ آزمون چهارم به‌علت در دسترس نبودن Ollama رد شد. این علت با اجرای همان ماژول و `-rs` بررسی شد.
- `npm test`: **۲۲ موفق** در سه فایل. `npm run build`: موفق (TypeScript و Vite).
- عدد تاریخی ۳۲۴ مربوط به وضعیت قدیمی‌تر است؛ commitهای اخیر آزمون اعتبارسنجی AI، trace و integration اضافه کرده‌اند. آخرین commit قبلاً ۳۳۷ موفق/۳ skipped گزارش کرده بود؛ در محیط فعلی آزمون چهارم Ollama نیز skip می‌شود.
- ابزار lint/type-check پایتون در `pyproject.toml` تعریف نشده؛ pytest ابزار توسعهٔ موجود است. بستهٔ تازه‌ای برای ممیزی نصب نشد.

## معماری بررسی‌شده

FastAPI سه خانوادهٔ legacy، administrator و agent به‌همراه API داشبورد دارد. توکن مدیر در تنظیمات است و عامل‌ها اعتبارنامهٔ مستقلِ هش‌شده در SQLite دارند. معرفی خودکار، تأیید مدیر و claim با اثبات کلید هویت جدا هستند. Task Dispatch و Console از صف تسک مرکزی استفاده می‌کنند. SQLite یک اتصال با RLock و WAL دارد. Monitor رویدادهای EVE را به events/alerts/hosts می‌نویسد. worker تحلیل AI از همان LLMClient برنامه استفاده می‌کند؛ تحلیل، فعالیت AI، حافظه، پرسش و پیشنهاد اقدام در جداول مستقل ذخیره می‌شوند. حافظهٔ پیشنهادی و اقدام اجرایی نیازمند تأیید مدیرند. Dashboard اطلاعات را از Backend می‌گیرد؛ توکن مدیر به prompt داده نمی‌شود.
